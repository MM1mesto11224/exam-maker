# نص القرآن الكريم

`quran-uthmani.txt` هو النص العثماني من **مشروع Tanzil** (https://tanzil.net) ويُستخدم دون أي تعديل.
شروط الاستخدام مذكورة في ذيل الملف نفسه: يُسمح بنسخه وتوزيعه كما هو، مع ذكر المصدر ووضع رابط tanzil.net، ويجب إبقاء إشعار الحقوق في كل نسخة.
لذلك لا تعدّل الملف، وأبقِ الإشارة إلى Tanzil في التطبيق.

الصيغة: كل سطر `رقم_السورة|رقم_الآية|نص_الآية`.
لاستبداله بنسخة أحدث: حمّلها من https://tanzil.net/download/ (Uthmani، Text) وضعها هنا بنفس الاسم.
