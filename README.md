# 📝 صانع الامتحانات المفتوح — Open Exam Maker

برنامج **مفتوح المصدر (MIT)** لإنشاء أوراق الامتحانات وطباعتها: لا تفعيل، لا أكواد، لا اشتراك، لا إنترنت مطلوب.
يعمل في المتصفح (ويُثبَّت كتطبيق PWA) وكتطبيق أندرويد (APK) من نفس الشيفرة.

**تصميم: [المدرس محمد مسطو](https://wa.me/963944943481)** — للتواصل عبر واتساب: https://wa.me/963944943481

## المزايا
- كليشة الامتحان (وزارة، مدرسة، شعار، مادة، صف، عام، دور، تاريخ، زمن، درجة) بأربعة تصاميم.
- أسئلة بفروع (أ، ب، ج…) مع درجة لكل سؤال/فرع، واختيار من متعدد، وسطور إجابة.
- محرر غني: عريض/مائل/خط/ألوان، أس وفهرس، **كسور وجذور**، رموز، **معادلات كيميائية** (H2SO4 ← H₂SO₄)، قوانين جاهزة، أشكال هندسية وزوايا، جداول، صور مع تفريغ الخلفية، فراغات، إملاء صوتي حيث يدعمه الجهاز.
- نموذج إجابة لكل سؤال وفرع، يُطبع في صفحة منفصلة أو وحده.
- تبويب درجات مع مطابقة المجموع للدرجة الكلية وتوزيع تلقائي.
- طباعة / PDF: نسخ متعددة، نسختان أو ثلاث في الصفحة، تصغير ليناسب صفحة أو صفحتين، إطارات وفواصل وملاحظة.
- تصدير **Word (.docx)** (الكسور والجذور تتحول إلى معادلات Word أصلية) و**Excel (.xlsx)** و JSON.
- تدقيق إملائي للأخطاء الشائعة وعلامات الترقيم.
- أرشيف امتحانات محلي + استيراد/تصدير.
- ورقة بالعربية أو الإنجليزية أو الفرنسية.
- البحث في آيات القرآن الكريم وإدراجها (النص من مشروع [Tanzil](https://tanzil.net) دون تعديل، وهو مضمَّن في `web/data`).

## التشغيل في المتصفح
لا يحتاج بناءً. افتح مجلد `web` بأي خادم ثابت:

    cd web && python3 -m http.server 8000     # ثم افتح http://localhost:8000

أو ارفع مجلد `web` على GitHub Pages أو Cloudflare Pages أو أي استضافة ثابتة.

## بناء ملف APK تلقائيًا (بدون برامج على جهازك)
1. أنشئ مستودعًا على GitHub وارفع كل محتويات هذا المجلد (Add file ← Upload files، مع المجلدات).
2. افتح تبويب **Actions** ← «Build APK» ← **Run workflow** (يعمل أيضًا تلقائيًا عند كل رفع).
3. بعد دقائق افتح التشغيل الناجح ونزّل **exam-maker-apk** ← فيه `app-debug.apk` للتثبيت مباشرة.

أو محليًا (JDK 17 + Android SDK): `gradle -p android assembleDebug`.

> ملاحظة: الـ APK الناتج موقَّع بمفتاح التصحيح (Debug) وهو صالح للتثبيت والاستخدام. للنشر على المتاجر وقّعه بمفتاحك.

## قوالب المواد الجاهزة
تبويب **البيانات** ← «قوالب المواد الجاهزة»: اختر المادة ثم الصف ثم الفرع/النموذج واضغط «تحميل القالب». يُحمَّل هيكل الامتحان (عناوين الأسئلة ودرجاتها وأنواع البنود) وتبقى بيانات المدرسة والمدرّس والشعار. قالب الأحياء للتاسع يخدم السابع والثامن والتاسع، وقالب الأحياء للثالث الثانوي العلمي يخدم العاشر والحادي عشر والثالث الثانوي. لا تتكرر المادة والصف والفرع في القائمة.

## نمط امتحان الإنكليزية والفرنسية
- تبويب **التنسيق** ← «نمط امتحان الإنكليزية» أو «الفرنسية» (والزر الثالث يعيد النمط العادي).
- تبويب **الأسئلة** ← «نموذج امتحان إنكليزي/فرنسي» يحمّل نموذجًا كاملًا بنصوص تجريبية قابلة للتعديل.
- كل «سؤال» يصبح قسمًا (A, B, C…) له عنوان ودرجة، ويُرقَّم كل فرع تسلسليًا عبر الأقسام، والورقة بعمودين مع كليشة عربية وحقلي الاسم والرقم وعبارة «انتهت الأسئلة».
- أنواع الفروع: نص عادي، اختيار من متعدد (a b c d)، صح/خطأ ( )، مزاوجة بين (A) و(B)، سؤال بسطور نقطية، وعنوان فرعي بلا رقم.
- الطباعة ونموذج الإجابة وWord وExcel تدعم الأنواع الجديدة.

## نسخة ويندوز (برنامج .exe)
مجلد `desktop/` غلاف Electron يعرض مجلد `web` نفسه دون أي نسخة ثانية من الشيفرة، ويضيف زر «حفظ PDF مباشرة».
1. بعد رفع الملفات إلى GitHub افتح **Actions ← Build Windows ← Run workflow** (يعمل أيضًا عند كل تعديل على `web` أو `desktop`).
2. بعد اكتمال البناء (✔) نزّل **exam-maker-windows** وفُكّ ضغطه، فتجد `ExamMaker-Setup-1.0.0.exe`.
3. شغّله لتثبيت البرنامج (يضيف اختصارًا على سطح المكتب وقائمة ابدأ).

محليًا: `cd desktop && npm install && npm start` للتجربة، و`npm run dist` لبناء ملف التثبيت (على ويندوز).

> ملاحظة: الملف غير موقَّع بشهادة مدفوعة، فقد يعرض ويندوز تحذير SmartScreen؛ اختر «مزيد من المعلومات ← تشغيل على أي حال».
